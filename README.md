# 🐾 SmartPet

SmartPet is a simple web application designed for pet lovers. It helps users explore pet-related services and provides an easy-to-use interface with a clean and responsive design.

## ✨ Features

- 🏠 Home Page
- 🐶 Pet Services
- 📖 About Page
- 📞 Contact Page
- 📱 Responsive Design
- 🎨 Simple & User-Friendly Interface

## 🛠️ Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/Siva22223333/Smartpet.git
```

Go to the project folder:

```bash
cd Smartpet
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the development server:

```bash
python manage.py runserver
```

Open your browser and visit:

```
http://127.0.0.1:8000/
```
